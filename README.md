# Inova Maranhão - Desafio 1

Portfólio pessoal gamificado desenvolvido para o primeiro desafio do programa Inova Maranhão / Trilhas.
O visitante assume o papel de “Jogador 1” e navega pelas informações profissionais como missões de um
jogo arcade.

## Tecnologias utilizadas

- HTML5 semântico;
- CSS3;
- Google Fonts: Press Start 2P e Sora.

O projeto não utiliza JavaScript, frameworks ou bibliotecas de componentes.

## Como executar

Não é necessário instalar dependências.

### Opção 1 — abrir diretamente

1. Baixe ou clone este repositório;
2. Abra a pasta do projeto;
3. Dê dois cliques no arquivo `index.html`.

O portfólio será aberto no navegador padrão.

### Opção 2 — servidor local

Caso tenha o Python instalado, abra o terminal na pasta do projeto e execute:

```bash
python -m http.server 8000
```

Depois, acesse `http://localhost:8000` no navegador.

## Funcionalidades

- Perfil profissional em estilo arcade;
- Barra de nível e lista de habilidades;
- Seção “Sobre mim” em formato de ficha de jogador;
- Links para projetos publicados no GitHub;
- Acesso aos certificados no Google Drive;
- Fundo personalizado e animado apenas com CSS;
- Layout responsivo para computadores e celulares;
- Navegação acessível por teclado.
